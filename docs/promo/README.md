# Promo images

| File | Size | Use |
|---|---|---|
| `banner.png` / `banner-zh.png` | 2560×1280 (1280×640 @2x) | README header, GitHub social preview |
| `instagram-en.png` / `instagram-zh.png` | 1080×1350 (4:5) | Instagram posts |

All four are generated by `build.py`, which writes `banner.html`, `banner-zh.html`, `ig-en.html` and `ig-zh.html`
(styled by `promo.css`) and renders them with headless Chrome. Edit the copy in `build.py`, then run:

```bash
python3 docs/promo/build.py
```

The images show the four values (complexity compression, IDE-native, source preservation, extensibility) and a
three-step example: a macro defined in plain C#, its one-line use, and the code the compiler gets.
